# beamcatch

beamrpg의 일곱 캐릭터와 떠나는 레트로 탐험·포획 RPG. 포켓몬스터 금·은의 마을 탐험, 풀숲 조우, 턴제 전투와 도감을 참고한 독립 오마주입니다.

## 실행

Node.js 20 이상에서 별도 설치 없이 실행할 수 있습니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 배포 시 `dist/`를 정적 웹 호스팅에 올리면 됩니다. ES 모듈을 사용하므로 index.html을 file://로 직접 여는 대신 HTTP 서버로 실행하세요.

## 플레이

- 방향키 / WASD: 한 칸 이동. 지도를 눌러도 이동합니다.
- E / 스페이스: 주변 NPC와 대화 또는 안내판 조사.
- 모바일: 방향 버튼과 대화 버튼.
- 풀숲을 걸으면 야생 빔몬이 등장합니다. `주변 탐색`으로 바로 조우할 수도 있습니다.
- `기술`로 HP를 낮추고 `포획`으로 빔볼을 던집니다. HP가 0이 되면 상대는 물러나므로 그전에 포획하세요.
- 새빛 마을, 잔물결 호수, 황금빛 유적은 오른쪽 위 지역 선택 메뉴로 이동합니다.
- 나의 동료에서 파트너 교체, 가방에서 보급품 구입, 마을에서 무료 전체 회복이 가능합니다.
- 6명 초과 동료는 보관함에 들어갑니다. 동료 목록에서 선두와 교환할 수 있습니다.
- 3회 포획 목표 달성 후 보상을 받고, 7종의 도감을 완성해 보세요.

## 저장과 범위

진행 상황은 이 브라우저의 localStorage(`beamcatch-v1`)에 자동 저장합니다. 서버 계정, 기기 간 동기화, 온라인 대전은 없습니다. 전투 도중 새로고침하면 탐험으로 복귀하며 이미 사용한 아이템과 HP는 유지됩니다. 보관함은 500명까지 저장하고, 이후 포획은 도감에만 기록합니다. 효과음과 수동 낮/밤 전환을 지원합니다.

## 구성

- `dist/index.html`, `dist/style.css`: 반응형 한국어 UI
- `dist/app.js`: 화면, 입력, 효과음 및 게임 흐름
- `dist/world.js`: Canvas 기반 원본 픽셀 맵, 이동과 충돌
- `dist/engine.js`: 턴제 전투, 포획, 성장, 보관함, 저장 검증
- `dist/creatures.js`: 캐릭터 7종의 능력치와 서식지
- `dist/assets/`: 원본 얼굴 이미지 7개

## 검증

```sh
npm test
```

전투·포획·아이템·파티·보관함·성장·저장 검증·회복·초기화에 대한 Node 내장 assert 테스트를 포함합니다. 브라우저 검증 기록은 `QA.md`에 정리했습니다.
