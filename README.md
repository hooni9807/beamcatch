# beamcatch

beamrpg와 spin-tt의 캐릭터로 떠나는 레트로 탐험·포획 RPG. v2에서는 12개 캐릭터 계열을 기본형 12종, 진화형 12종, 희귀 변종 12종으로 확장해 총 36종을 수집할 수 있습니다. 포켓몬스터 금·은의 마을 탐험, 풀숲 조우, 턴제 전투와 도감을 참고한 독립 오마주입니다.

[GitHub Pages에서 플레이](https://hooni9807.github.io/beamcatch/) · [소스 저장소](https://github.com/hooni9807/beamcatch)

## 실행

Node.js 20 이상에서 별도 설치 없이 실행할 수 있습니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 배포 시 `dist/`를 정적 웹 호스팅에 올리면 됩니다. ES 모듈을 사용하므로 index.html을 file://로 직접 여는 대신 HTTP 서버로 실행하세요.

## 플레이

- 방향키 / WASD: 한 칸 이동. 지도를 눌러도 이동합니다.
- E / 스페이스: 주변 NPC와 대화 또는 안내판 조사.
- 모바일: 방향 버튼과 대화 버튼.
- 풀숲을 걸으면 야생 빔몬이 등장합니다. `주변 탐색`으로 바로 조우할 수도 있습니다.
- `기술`로 HP를 낮추고 `포획`으로 빔볼을 던집니다. HP가 0이 되면 상대는 물러나므로 그전에 포획하세요.
- 빛·풀·꿈·불꽃·그림자·물·전기·바람·강철·얼음, 10개 속성의 상성이 전투에 적용됩니다. 유리하면 피해 1.5배, 불리하면 0.75배, 그 외에는 1배입니다. 도감의 `상성 안내`에서 관계를 확인할 수 있습니다.
- 새빛 마을, 잔물결 호수, 황금빛 유적은 오른쪽 위 지역 선택 메뉴로 이동합니다.
- 나의 동료에서 파트너 교체, 가방에서 보급품 구입, 마을에서 무료 전체 회복이 가능합니다.
- 6명 초과 동료는 보관함에 들어갑니다. 동료 목록에서 선두와 교환할 수 있습니다.
- 선두 동료가 전투·포획 경험치를 얻습니다. 기본형이 Lv. 10 이상이 되면 전투 밖에서 `나의 동료 → 진화하기`를 눌러 원하는 때 진화할 수 있습니다. 보관함의 동료도 진화할 수 있으며 같은 동료의 레벨·경험치·식별자는 유지됩니다. 진화 전후 형태가 모두 도감에 남습니다.
- 진화형 12종은 기본형을 키워 얻습니다. 희귀 변종 12종은 기본형과 속성이 다르며 별도로 포획합니다. 지도 위 해·달 버튼이나 설정에서 낮/밤을 바꾸면 해당 시간에만 나타나는 변종을 찾을 수 있습니다.
- 도감에서 이름·속성·원래 캐릭터로 검색하고, 수집·진화형·희귀 변종을 골라 볼 수 있습니다. 각 항목을 누르면 서식지와 출현 시간, 진화 계열을 확인할 수 있습니다.
- 3회 포획 목표 달성 후 보상을 받고, 36종의 도감을 완성해 보세요.

## 저장과 범위

진행 상황은 이 브라우저의 localStorage(`beamcatch-v1`)에 자동 저장합니다. v2도 같은 저장 키를 사용하며 기존 7종의 ID와 기본 능력치를 유지해 v1의 동료·레벨·도감·아이템·보관함 기록을 이어받습니다. 같은 브라우저와 사이트 주소에서 플레이해야 기존 저장을 읽을 수 있습니다.

서버 계정, 기기 간 동기화, 온라인 대전은 없습니다. 전투 도중 새로고침하면 탐험으로 복귀하며 이미 사용한 아이템과 HP는 유지됩니다. 보관함은 500명까지 저장하고, 이후 포획은 도감에만 기록합니다. 효과음과 수동 낮/밤 전환을 지원합니다. 낮/밤은 실제 시각과 무관하며 희귀 변종의 출현에 영향을 줍니다.

## 구성

- `dist/index.html`, `dist/style.css`: 반응형 한국어 UI
- `dist/app.js`: 화면, 입력, 효과음 및 게임 흐름
- `dist/world.js`: Canvas 기반 원본 픽셀 맵, 이동과 충돌
- `dist/engine.js`: 속성 상성, 턴제 전투, 포획, 성장·진화, 보관함, 저장 검증
- `dist/creatures.js`: 36종의 능력치, 기술, 서식지, 출현 시간과 진화 계열
- `dist/assets/`: 원본 이미지 12개 (12개 캐릭터 계열)
- `ASSETS.md`: 이미지별 원본 저장소·커밋·경로
